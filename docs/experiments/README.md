Пять наиболее ценных экспериментов, в порядке исполнения:

1. **E1: cadence + gaps.** Отличать отсутствие нового измерения от нормы, зависания и потери связи; считать выдержку по независимым обновлениям.
2. **E2: machine vs sensor.** Проверять согласованность каналов и временную форму отклонения; диагностировать конкретный канал, а не случайное совпадение с окном события.
3. **E3: regime + UNKNOWN.** Проверить нормальные изменения режима и явно отказываться от неподтверждённого типа.
4. **E4: contaminated reference.** Измерить цену 24-часового ожидания и загрязнения опоры исходной неисправностью; отдельное исследование, не изменение B2 v1.
5. **E5: sensor mask/restore.** Проверить пользу уже существующих датчиков на богатых train/validation активах. Не синтезировать дополнительные каналы PUMP-11.

В causal B2 v1 входят E1–E2 и обязательное честное поведение UNKNOWN. E3–E5 зарегистрированы, но не дают разрешения расширить поиск или подстроить B2 после просмотра validation. Если времени недостаточно, сдать проверенный B2 и явный список невыполненных опытов.

Все данные synthetic. Из этих результатов нельзя выводить абсолютную диагностику, переносимость на реальную установку или доказанную экономию.
