# Task 005 — remaining regime, abstention and reference hypotheses

Planning task for Claude Code after Task004. Read the finite registry H2/H3/H6 and frozen-protocol limitations. One code writer; no Git mutation. Budget 90 minutes; preserve a partial result if needed, and state which hypothesis was not tested. This document does not authorize changes to the Task002 seal or any test-set access.

The questions are whether normal operating transitions cause avoidable nuisance, whether explicit abstention reduces wrong specific diagnoses without losing anomaly alerts, and whether a causal reference-quality check or transferable prior helps cold-start/pre-existing faults. Do not assume that a positive answer is possible on this dataset.

## Register before executing

Use two internal handoffs. First implement the exact candidate definitions and constructed-fixture checks and write the proposed manifest, then return to Codex for a focused review before any new benchmark scoring. This is a coordinator review, not a request for user permission. After that review, freeze the hashes and complete the registered train/eligible-validation run and findings. This avoids discovering a changed experiment definition only after outcome exposure.

Create a separate, dated experiment manifest and explanation under docs/experiments/followup/. Specify exact equations/thresholds, consumed channels, time-availability rules, reference sample requirements, training/fitting roles, fixed candidate IDs, seed, denominators and selection rules. A generic “regime-aware” label is insufficient. Use public sensor metadata and train information only to define the candidates. Do not derive parameters from validation outcomes or hidden generator scenarios. Record prior train and validation exposure honestly.

Maximum budget: control plus two regime/abstention variants and two reference variants. No iterative expansion after seeing their results. These are separate E3/E4 experiments, not B2 v1 reruns. Preserve causal B1 and the selected Task002 artifact as unchanged controls. Regime suppression must report loss of diagnostic coverage, not replace missing support with healthy. An UNKNOWN variant must retain the anomaly alert and distinguish uncertain class from the scorer's required class label.

A reference variant needs a defensible scale across pumps. If a data-driven prior is used, fit only on the other six train assets in each LOAO fold and record exactly which train-label information selects fit windows. Train-normal selection does not certify health. A held-out pump's future data or fault labels cannot contribute to its prior. A physical/nameplate residual requires explicit equations, units, uncertainty and missing-input handling. If available metadata cannot support transfer, report that limitation rather than treating raw pressures/current across different pumps as interchangeable. An oracle clean reference, if used at all, is clearly an evaluator-only upper bound and never a deployable candidate.

E3 must show whether fewer errors merely reflect less diagnostic coverage; include a coverage-matched comparison or explicitly state that such support is absent.
